# U7 機能設計：保護者向けの「学習のようす」

2026-11-12 にユーザーと決めた内容（「案のとおり」）。U8（ログイン・同期）の前に、端末の記録だけで作る。

## 画面
保護者メニュー（PIN が要る）→「学習のようす」（`/parent/insights`）。子どもが2人以上なら、切り替えて見る。

| 区画 | 内容 |
|---|---|
| まとめ | 登録した間違いの数、撃破した数（と割合）、再来の撃破率（目安 60%・再来の回数）、連続記録（いちばん長い記録） |
| 教科ごと | 教科ごとの数と、撃破した数（横の棒） |
| よくある間違い TOP5 | 間違いのタイプごとの数と、撃破した数（横の棒、教科つき） |
| 推移（直近8週） | 週ごとの「登録した数」（たての棒）と「再来の撃破率」（折れ線、目安 60% の点線）。表でも見られる |

## ルール
- **再来の撃破率**：日程どおりの再来のバトルのうち、撃破した割合。れんしゅう（BR-6-1）は数えない。再来がなければ「まだなし」（0% と見分ける）。
- 週は月曜から日曜。日付は端末の「今日」（U6-TIME-1）で決める。
- 言い方は事実だけにする。「苦手」「発達」のような、評価や診断めいた言葉は使わない（NFR-P10）。
- AI による傾向のまとめは、MVP に入れない（stories.md の範囲のまとめのとおり）。
- U8 ができるまでは、子どもが使っている端末の記録だけを集計し、そのことを画面に書く。

## NFR・インフラ
- 計算は `domain/parent/insights.ts`（純粋な関数・単体テスト）。U6 と同じく、バトルの記録から毎回計算する。
- グラフはライブラリを使わず SVG で描く。1つのグラフに1つの値だけ（2つの軸を持つグラフは作らない）。色は1色、値は文字と表でも出す。なぞる・フォーカスすると、その週の値を出す。
- 新しいクラウドの資源・ライブラリはなし。画面は事前にキャッシュする（オフラインでも開ける）。
