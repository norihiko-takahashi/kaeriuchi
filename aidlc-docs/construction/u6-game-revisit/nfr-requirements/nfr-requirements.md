# U6 NFR 要件：ゲーミフィケーション・再来

U1・U2・U4・U5 の NFR はそのまま引き継ぎます。ここには、U6 で新しく決めることだけを書きます。★ は 2026-11-12 にチャットで決めたものです。

| # | 要件 |
|---|---|
| U6-PERF-1 | XP・レベル・図鑑・連続記録・再来の日程の計算は、端末で 50ms 以内（ミスモン 1,000匹・バトル 5,000回で測る） |
| U6-PERF-2 | ホームの表示（今日の再来・レベル・連続記録）は、IndexedDB から読んで 200ms 以内 |
| U6-PERF-3 | 子ども向けの新しい画面（テスト・図鑑）の JavaScript は 200KB 以内（U1-PERF-2） |
| U6-DATA-1 | XP・図鑑・連続記録・再来の日程は保存した数字を足していかず、バトルの記録から計算し直す（U8 で2つの端末の記録をまとめても食い違わない・domain-model.md） |
| U6-DATA-2 | 学習の記録には日付だけを残し、時刻は残さない（NFR-P11） |
| U6-TIME-1 | ★ 「今日」は端末の時計で決める。日付が前の記録より戻っていたら（時計を戻した）、連続記録と再来の日程を進めない。サーバーの日付との照らし合わせは U8 で行い、大きくずれていたら保護者に知らせる |
| U6-RUBY-1 | AI が返した読みは、ひらがなだけか、語が文の中にあるか、語に漢字があるかを確かめ、合わないものは捨てる（BR-6-7）。読みの数は1問につき 30語まで |
| U6-A11Y-1 | レベルアップ・図鑑の登録の演出は、「視差効果を減らす」設定で止め、文字と読み上げでも伝える |
| U6-TEST-1 | 純粋な関数（XP・レベル・図鑑・連続記録・再来・テストの進み具合）は、カバレッジ 90% 以上。日付をまたぐ場合（月曜のチケット、月末、うるう年、時計を戻した場合）を表のテストで網羅する |
