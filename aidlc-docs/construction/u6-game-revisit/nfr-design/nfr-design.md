# U6 NFR 設計：ゲーミフィケーション・再来

新しい外部のライブラリは入れません。

## 1. ディレクトリ

```
content/game/rules.json      # XP・レベル・再来の間隔・1日の再来の数（BR-6-2・6-4）
domain/game/
├─ review.ts                 # 再来の日程（バトルの記録 → 段階と次の日）
├─ xp.ts                     # XP とレベル
├─ dex.ts                    # 図鑑（まだ・銅・銀・金）
├─ streak.ts                 # 連続記録とお休みチケット
├─ sheet.ts                  # テストの進み具合とクリア
└─ clock.ts                  # 「今日」と、時計が戻っていないか（U6-TIME-1）
server/ai/ruby.ts            # AI が返した読みの確かめ（U6-RUBY-1）
client/store/game-repo.ts    # テスト・再来・ゲームの状態を読む
app/sheets, app/sheets/detail, app/dex
```

## 2. 計算の形

- どの関数も「バトルの記録の一覧と、今日の日付」を受け取り、結果を返すだけにする（保存しない）。
- 画面を開くたびに計算する。数が増えても U6-PERF-1 に収まるよう、ミスモンごとにまとめてから計算する。
- XP の内訳（撃破・ヒントなし・ヒントの分など）は、結果の画面で見せるために、バトルの記録から同じ関数で出す。

## 3. 端末に残すもの（IndexedDB のスキーマ v3）

| 表 | 変更 |
|---|---|
| `sheets`（新しい） | テスト：名前、教科、作った日、ミスモンの ID の一覧 |
| `mistakes` | `sheetId` を足す。v2 のミスモンは、教科と作った日ごとに「テスト」を作って入れる（移行の処理と単体テスト） |
| `battles` | 変えない（`mode` に `sheet` を足す） |
| `meta` | 最後に見た日付（U6-TIME-1） |

## 4. ふりがな

- `ProblemDraft` に `ruby?: { word: string; reading: string }[]` を足し、プロンプトを `generate@3` にする。
- `server/ai/ruby.ts` で確かめ、合わないものは捨てる。検証の流れ（pipeline）の最後に入れる。
- 画面では、文の中のその語を `<ruby>` で包む。付けるかどうかは U1 の `needsRuby` で決める。

## 5. テスト

- `domain/game/**` は表のテストで網羅する（U6-TEST-1）。
- E2E：撃破 → 翌日（端末の時計を進める）に再来が出る、テストの「まとめて たたかう」でクリア、図鑑の銅、中学生モードの言葉。
