# U6 コードの作成：まとめ

偽物の AI で、「撃破 → 翌日に再来 → 図鑑が銀に」「テストを選んで、まとめて復習」まで動くようにしました。

## 1. 作ったもの

| 場所 | 内容 |
|---|---|
| `content/game/rules.json` | XP・レベル・再来の間隔・1日の再来の数・お休みチケット（β版で変える） |
| `domain/game/` | 再来の日程（`review.ts`）、XP とレベル（`xp.ts`）、図鑑（`dex.ts`）、連続記録（`streak.ts`）、テストの進み具合（`sheet.ts`）、「今日」の決め方（`clock.ts`）。どれもバトルの記録から計算する純粋な関数 |
| `server/ai/ruby.ts`、`prompts`（`generate@3`） | AI に漢字の語と読みを返させ、ひらがなだけか・文の中にあるか・漢字があるかを確かめる。読みも安全のチェックに入れる |
| `client/store/db.ts`（スキーマ v3） | テスト（`sheets`）を足す。v2 のミスモンは、子ども・教科・登録した日ごとのテストに入れる。終えたバトルに順番を付ける |
| `client/store/clock.ts` | 「今日」。端末の時計が前に見た日より戻っていたら、前に見た日を使う |
| `client/store/game-repo.ts` | テストの作成・名前の変更、ゲームの状態（XP・レベル・連続記録・図鑑・今日の再来・テストの進み具合）、結果の画面でもらったもの |
| `components/ruby-text.tsx` | AI が作った文のふりがな（その学年で習っていない漢字の語だけ） |
| `client/battle/words.ts` | 中学生モードの言葉（「撃破」「解く」「弱点ノート」など） |
| `app/home` | レベルと XP のバー、連続記録、今日の再来（1日5匹まで）、まだ倒していないミスモン、テスト・図鑑への入り口 |
| `app/mistakes/new` | 「どの テスト？」（あたらしい テスト、または同じ教科の最近のテスト） |
| `app/battle` | 初回・再来・れんしゅうを記録から決める。結果の画面に XP の内訳・レベルアップ・図鑑・連続記録。テストのまとめての復習で「つぎの ミスモンへ」 |
| `app/sheets`、`app/sheets/detail`、`app/dex` | テストの一覧（S-30）、テスト（S-31、名前を変える、まとめて たたかう）、図鑑（S-32、中学生モードは「弱点ノート」） |
| 報告の理由 | 「よみがなが へん」を足した |

## 2. 確かめたこと（ローカル・Node.js 26）

| 確認 | 結果 |
|---|---|
| 単体テスト | 327件すべて成功。`domain/`・`server/ai/`・`server/problems/` のカバレッジは行 99.1%・分岐 96.8% |
| 速さ | ミスモン 1,000匹・バトル 5,000回の計算が 50ms 以内（単体テストで確認） |
| スキーマの移行 | v1 → v3、v2 → v3（ミスモンをテストに入れる、バトルに順番を付ける）を単体テストで確認 |
| E2E（Chromium） | 12件成功。U6 の2件：撃破 → 翌日に再来（Playwright の時計で日付を進める）→ 図鑑が銀・レベル2・連続2日・今日の再来はおしまい／テストの一覧とクリア、名前の変更、まとめての復習（れんしゅう、XP +10）。どちらも axe と CSP の違反なし |
| 大きさの予算 | 新しい子ども向けの画面は 176〜190KB（予算 200KB）。バトルの画面が 190KB で、予算に近づいている |
| WebKit の E2E | CI で確かめる |

## 3. 設計から変えたところ・足したところ

| 設計 | 実際 | 理由 |
|---|---|---|
| `battles.mode` に `sheet` を足す（nfr-design §3） | `practice`（れんしゅう）を足した。テストのまとめての復習は、ミスモンごとに初回・再来・れんしゅうのどれかになる | 2026-11-12 に決めた「れんしゅう」の扱いに合わせた |
| 「今日の再来はおしまい」は上限の5匹に届いたとき（BR-6-2） | 今日の予定の分を全部倒したときも出す | 予定が3匹なら3匹倒したところで「おしまい」と見せないと、終わったのかがわからないため |
| U5 で「あと一歩」のミスモンは、次は再来（2問）になっていた | 撃破したことがなければ、次も初回（3問）にした | 再来は「撃破したミスモンが、忘れかけたころに出る」もののため |
| バトルの順番 | 時刻の代わりに、終えた順の番号を付ける | 学習の記録に時刻を残さない（NFR-P11）まま、同じ日の中の順番を決めるため |
