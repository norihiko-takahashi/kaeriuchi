# U6 機能設計：ビジネスルール

2026-11-11 にチャットで1つずつ決めたもの（★）と、それに合わせた細かいルール。

## BR-6-1 テスト ★

- 手で入れるときに、テストを選ぶ。初めは「あたらしい テスト」。
- 名前は「<教科> <月>/<日> の テスト」を自動で付ける。変えられる（1〜30字）。
- 1つのテストに入れられる間違いは 30問まで。
- クリア：そのテストのミスモンを全部1回以上撃破した。
- 進み具合：撃破したことがあるミスモンの数 / ミスモンの数。

## BR-6-2 再来の日程

| 段階 | 次の再来 |
|---|---|
| 初めて撃破 | 1日後 |
| 再来1回目を撃破 | 3日後 |
| 2回目 | 7日後 |
| 3回目 | 14日後 |
| 4回目 | 30日後 |
| 5回目（30日後）を撃破 | 完全撃破。もう出てこない |

- 初めてのバトルで「あと一歩」：翌日にまた出る（BR-45-6）。段階は変えない。
- 再来で「あと一歩」：段階を最初に戻し、翌日にまた出る（FR-7.3）。
- 予定の日を過ぎても、消えずに「今日の再来」に残る。
- 今日の再来の数に上限は付けない（並びは、予定の日が古い順）。

## BR-6-3 図鑑 ★

- 種族は、間違いのタイプごとに1つ。
- カードは「まだ → 銅 → 銀 → 金」と、強い方にだけ進む（戻らない）。
  - 銅：そのタイプのミスモンを初めて撃破した
  - 銀：そのタイプのミスモンの再来を、初めて撃破した
  - 金：そのタイプのミスモンを完全撃破した
- 見つけただけ（まだ撃破していない）のタイプは、シルエットで出す。

## BR-6-4 XP とレベル ★

| できたこと | XP |
|---|---|
| 撃破（初めて） | +50 |
| 再来の撃破 | +40 |
| 完全撃破（5回目の再来の撃破） | +100（再来の撃破の代わり） |
| ヒントなしで全問正解 | +30（「あってるのに ×」で正解にした問題があればなし） |
| ヒントを見た | 1つにつき −5（撃破の XP は 20 より下がらない） |
| あと一歩 | +10 |
| 報告 | なし（FR-5.6） |

- レベル L から L+1 に上がるのに要る XP：100 + 50 ×（L − 1）。レベル1から始まる。
- 数字は `content/game/rules.json` に置く。

## BR-6-5 連続記録 ★

- 1日に1回、バトルを最後までやれば、その日は「できた」（撃破でもあと一歩でもよい。途中でやめたものは数えない）。
- 1日の区切りは端末の午前0時（BR-3.3）。
- お休みチケット：週に1枚（月曜に配る。ためておけるのは1枚まで）。できなかった日があったら、自動で使って記録をつなぐ。
- 記録が途切れても、「いちばん ながかった きろく」は残す。責める言い方はしない。
- 保護者が使えなくした時間帯の日も、普通の日と同じに数える。
- 計算は、バトルを最後までやった日の一覧から行う（保存した数字を足していかない）。

## BR-6-6 中学生モード ★

- 色をおさえ、ミスモンを小さくし、ゆらゆら動く演出を止める（正解のときの短い動きだけ残す）。
- 言葉を漢字まじりにし、子どもっぽい言い方を控える（例：「げきは！」→「撃破」、「たたかう」→「解く」）。
- XP・図鑑・連続記録はそのまま使う。図鑑は「弱点ノート」として見せ、何を直したかがわかるようにする。
- ふりがなと読み上げは出さない（U1 のまま）。

## BR-6-7 ふりがな ★

- 問題を作るときに、AI に漢字の語とその読みの一覧（`ruby`）を返させる。プロンプトの版を上げる。
- サーバーで確かめる：読みがひらがなだけか、語が問題文・ヒント・解説・選択肢のどれかに本当にあるか、語に漢字が入っているか。合わないものは捨てる（問題そのものは出す）。
- 画面では、その学年までに習っていない漢字を含む語にだけ付ける（U1 の `needsRuby`）。
- 報告の理由に「よみがなが へん」を足す（「そのほか」の前）。
