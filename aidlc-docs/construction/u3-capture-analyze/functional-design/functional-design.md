# U3 機能設計：撮影・切り抜き・解析

2026-11-13 にユーザーと決めた点（AskUserQuestion）：

| # | 点 | 決定 |
|---|---|---|
| 1 | 元の写真の置き場所 | **画面を開いている間だけ**（メモリの中）。端末には保存しない。途中で画面が消えたら撮り直し |
| 2 | カメラ | **スマホのカメラを呼ぶ**（`<input type="file" accept="image/*" capture="environment">`）。「しゃしんを えらぶ」も同じ画面から |
| 3 | 読み取り結果の確認 | **1問ずつ順に**（「1/3」）。いまの確認の画面の作りを使う |
| 4 | 教科 | **撮る前に選ぶ**（「わからない」もある。そのときは AI が推定） |

前から決まっていること：子どもが指で囲む（自動の候補なし、FR-2.5a）、かくすペン（FR-2.5c）、送るのは枠の中だけ（FR-2.5d）、名前などは伏せ字（US-3.3）、1回の撮影は1つの「テスト」にまとめる（FR-2.7）。

## 流れ（子どもの画面）

```
ホーム「📷 ミスモンを よぶ」
 → ① きょうかを えらぶ（さんすう・こくご・えいご・りか・しゃかい・わからない）
 → ② しゃしんを とる ／ しゃしんを えらぶ
 → ③ まちがえた もんだいを ゆびで かこむ（何問でも）
 → ④ なまえが うつっていたら かくすペンで けす（とばせる）
 → ⑤ おくる（枠ごとに読み取る。「2/3 よみとりちゅう…」）
 → ⑥ 1問ずつ たしかめる（「1/3」）。直せる。読み取れなかった問題は「とりなおす」「じぶんでいれる」
 → ⑦ とうろく → ミスモンが あらわれた（何匹か）→ たたかう／ホーム
```

## ルール

### 写真（決定 1・2）
- 写真は画面の中（メモリ）でだけ扱う。IndexedDB・キャッシュ・ファイルには書かない
- 読み込むときに向きを直し（写真の向きの情報どおりに回す）、長い辺を 2048px に縮めて扱う。元の大きさのデータはすぐに捨てる
- 次のときに写真を捨てる：登録が終わった、やめた、別の画面に移った、アプリが裏に回って 10分たった。捨てたあとに戻ってきたら「もういちど とってね」
- カメラの権限は要らない（スマホのカメラを呼ぶため）。写真を選べないときは「てで いれる」を案内する

### 囲む（FR-2.5a・b）
- 1本の指でなぞると四角ができる。四角を押すと選べて、角の取っ手（押せる大きさ 44px）で広げる・狭める、中をなぞって動かす、「けす」で消す
- 2本の指で、写真を大きくする・動かす（細かいところを囲むため）
- 小さすぎる枠（短い辺が写真の短い辺の 4% より小さい）・大きすぎる枠（写真の面積の 60% より大きい）には注意を出す（US-2.2）。大きすぎる枠はそのままでも送れるが、「なまえが はいっていないか たしかめてね」と出す
- 枠の数は、その日にあと登録できる数まで（保護者が決めた1日の上限・BR-3.1）。上限に届いたら「きょうは ここまで」と出して、枠を足せなくする
- 枠には番号（1・2・3…）を付け、確認のときの順番にする（上から下、同じ高さなら左から）

### かくすペン（FR-2.5c）
- 「かくすペン」を押すと、なぞったところを黒く塗る（太さは2種類）。「もとにもどす」で1回ずつ戻せる
- 塗ったところは、切り抜く前に写真そのものを黒くする。塗る前の画素は送らない
- 枠の外を塗っても送らないので意味はないが、止めない（子どもが安心できるように）

### 送る（FR-2.4・2.5d）
- 枠ごとに切り抜いて、JPEG（長い辺 1600px まで、品質 0.85、2MB まで）にしてから送る。写真の撮影情報（位置など）は付けない（描き直すので消える）
- 送り先は、いまの `/api/ai/analyze`（U2）。教科を選んでいれば一緒に送る。2枚ずつ並べて送る
- オフラインなら送らずに「インターネットに つながってから おくってね」と出す（写真は画面を開いている間は残る）
- 1枚が失敗しても、ほかは続ける。失敗した枠は、確認のときに「とりなおす」「じぶんでいれる」を出す

### 確かめる（FR-3.2・3.3、決定 3）
- 1問ずつ、切り抜いた画像と、読み取った「もんだい」「きみのこたえ」「せいかい」「まちがいのタイプ」を並べる。どれも押して直せる
- 信頼度が低い項目（0.7 未満）は色と「たしかめてね」の文字で示し、「あってる」を押すまで次へ進めない
- サーバーが名前などを見つけて伏せ字にしたときは「なまえが うつっていたかも。つぎは かくすペンで けしてね」と出す（US-3.3）
- 「この もんだいは やめる」で、その枠だけ登録しない

### 登録（FR-2.7・3.4）
- 確かめた問題を、まとめて1つの「テスト」に登録する（名前は教科と日付から。教科が「わからない」なら、いちばん多かった教科）
- ミスモンの記録の `source` に `"photo"` を足す（いまは `"manual"` だけ）
- 切り抜いた画像も保存しない。登録したら捨てる

### 写り込み（NFR-P4、US-3.3）
- スパイクの文字の規則（`spikes/r1/pii-text.ts`）を `server/ai/` に移し、`/api/ai/analyze` の結果（問題文・答え）に当てる。見つけたら伏せ字（〇〇）にして、伏せる前の文字は返さない・記録しない
- 見つけた率・誤って止めた率の目標は、AWS の準備のあとに本物の写真で測る

## NFR・インフラ
- 新しいクラウドの資源・ライブラリはなし（画像の処理はブラウザの Canvas）
- 子どもの画面の JavaScript の予算（200KB）に入れる
- 切り抜き・縮小・塗りつぶし・並べ替えは、ブラウザの部品と切り離した純粋な関数にして単体テストを付ける
- E2E：偽物の AI で、撮る → 囲む → 塗る → 送る → 確かめる → 登録、までを通す。送られた画像が枠の大きさで、写真全体ではないこと、塗ったところが黒いことを、通信の中身で確かめる（US-2.3）
- iOS Safari と Android Chrome の実機での確認は、Issue #8 にまとめて行う

## まだ決めないこと
- β版の「点だけ」の手伝い（R1 の試作を使う）
- 読み取りの精度の目標（AWS の準備のあと、U2 の評価の仕組みで測る）
