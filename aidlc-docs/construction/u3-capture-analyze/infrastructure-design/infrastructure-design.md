# U3 インフラ設計：撮影・切り抜き・解析

**新しいクラウドの資源はありません。**

- 画像の処理はすべて端末のブラウザの中で行う。
- 読み取りは、いまの `/api/ai/analyze`（U2）を使う。本物の AI（Bedrock）は AWS の準備のあとにつなぐ。それまでは偽物の AI で動かす。
- 送られた画像はサーバーのメモリの中だけで扱い、保存しない（U2 のまま）。ログに画像や読み取った文字は残さない。
- 画面は事前にキャッシュする（`/capture` を Service Worker の一覧と、大きさの予算の一覧に足す）。ただし、読み取りにはインターネットが要る。
- CSP は変えない（`img-src` に `blob:` がすでにある）。
