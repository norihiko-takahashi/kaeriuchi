# U3 コードの作成：まとめ

| 場所 | 内容 |
|---|---|
| `domain/capture/geometry.ts` | 枠の計算（作る・動かす・角で大きさを変える・はみ出さない・並べ替え・小さすぎ／大きすぎの注意・読み上げの位置・縮める大きさ）。単体テストつき。nfr-design.md の `crop.ts` の計算（縮める大きさ）もここに入れた |
| `server/ai/pii.ts` | 名前などの伏せ字（スパイクの規則を移した）。`/api/ai/analyze` の結果の問題・答え・説明に当てる。ログには種類の数だけ |
| `shared/capture.ts` | 画面とサーバーで共有する解析の結果の型（Zod の形と同じことをテストで確かめる）、信頼度の基準 0.7 |
| `client/capture/photo.ts` | 写真を読む（向きを直して 2048px に縮める）・捨てる。メモリの中だけ |
| `client/capture/redact.ts` | かくすペンの線を黒で描く |
| `client/capture/export.ts` | 枠を切り抜き、線を上から描いて JPEG（1600px・0.85、2MB を超えたら品質を下げる） |
| `client/capture/queue.ts` | 2枚ずつ並べて送る。1日の上限のエラーで残りを止める（単体テストつき） |
| `client/ai/api.ts` | `analyzeImage`（multipart で送る） |
| `client/store/battle-repo.ts` | `registerPhotoMistakes`：新しいテスト1つにまとめて、1つのトランザクションで入れる。1日の上限を超えるなら1問も入れない（単体テストつき）。`Mistake.source` に `"photo"` |
| `components/capture/frame-editor.tsx` | 写真と枠。1本の指でなぞる・動かす・角で大きさ、2本の指で拡大、キーボードでも操作できる。写真のキャンバスはそのまま画面に置く（複製を作らない） |
| `components/capture/review-step.tsx` | 1問ずつの確認。信頼度の低い項目は「たしかめてね」で、確かめるまで進めない。読み取れなかったら「もういちど よみとる」「じぶんで いれる」「やめる」。伏せ字にしたら知らせる |
| `app/capture/page.tsx` | ① 教科 → ② 撮る・選ぶ → ③ 囲む → ④ かくすペン → ⑤ 送る → ⑥ 確かめる → ⑦ 登録。登録・やめる・画面の移動・裏に回って10分で写真を捨てる |
| `app/home/page.tsx` | 「📷 ミスモンを よぶ」を使えるようにした |
| `app/globals.css` | `.card` を部品の層に入れた（選んだボタンの太い枠が出ていなかった。「手で入れる」画面にもあった不具合） |

## 確かめたこと（ローカル）
- 単体テスト 364件成功（`geometry.ts` 行の網羅 100%、`pii.ts` 100%）
- E2E 14件成功（Chromium）。新しい2件：
  - 合成画像を選ぶ → 2つ囲む → かくすペン → 送る → 1問ずつ確かめる → まとめて登録 → ホームに2匹。送った画像が2枚で、枠の大きさ（写真全体ではない）、JPEG、塗ったところが黒く・塗っていないところは白いことを確かめる。axe・CSP の違反なし
  - 読み取りが失敗 → 「じぶんで いれる」で登録できる
- 画面の大きさ：撮影 189.6KB、ホーム 190.7KB（予算 200KB）
- スマホの幅の画面写真で、囲む・塗る・確かめる・あらわれた の画面を目で確かめた
