# U3 NFR 要件：撮影・切り抜き・解析

U1・U2・U4〜U7 の NFR はそのまま引き継ぎます。ここには、U3 で新しく決めることだけを書きます。

| # | 要件 |
|---|---|
| U3-PRIV-1 | 写真は、画面を開いている間だけメモリに置く。IndexedDB・Cache Storage・ファイル・ログに書かない。登録・やめる・画面の移動・裏に回って 10分で捨てる（機能設計の決定 1） |
| U3-PRIV-2 | 端末の外に出るのは、確定した枠の中を切り抜いた画像だけ。かくすペンで塗ったところは黒くしてから切り抜く。写真全体・縮める前のデータ・撮影情報（位置など）は送らない（NFR-P2・FR-2.5d） |
| U3-PRIV-3 | 読み取った文字に名前の欄・学校名・クラス・先生・連絡先の形があれば、サーバーで伏せ字（〇〇）にしてから返す。伏せる前の文字は返さない・ログに残さない（US-3.3） |
| U3-PERF-1 | 写真を読み込んで囲む画面が出るまで 1.5秒以内（中くらいのスマホ、1,200万画素の写真で） |
| U3-PERF-2 | 1枠の切り抜き・塗りつぶし・JPEG にするまで 300ms 以内 |
| U3-PERF-3 | 読み取りは1枠ずつ U2-PERF-1（p90 で 8秒）。2枠ずつ並べて送り、5枠なら 25秒以内に全部そろう |
| U3-PERF-4 | 撮影の画面の JavaScript は 200KB 以内（U1-PERF-2） |
| U3-MEM-1 | 写真は長い辺 2048px に縮めて持つ（1枚 約16MB）。メモリの少ない端末でも落ちないよう、同時に持つ写真は1枚だけ |
| U3-COST-1 | 1回の撮影で囲める枠は **10個まで**、かつ、その日にあと登録できる数まで。読み取りの回数は、いまの上限（端末ごとに1日30回・BR-U2-3）を使う |
| U3-COMPAT-1 | iOS Safari 17 以上・Android Chrome の最新2版。写真の形式は JPEG・PNG・HEIC（ブラウザが読めるもの）。読めないときは「この しゃしんは よめなかったよ」と出して、撮り直し・手で入れるを案内する |
| U3-A11Y-1 | 指で囲めない人のために、キーボードでも枠を作って動かせる（Tab で枠を選ぶ、矢印で動かす、Shift＋矢印で大きさ）。どちらも難しいときは「てで いれる」を案内する。読み上げでは、枠の番号と、写真の中の位置（上の方・まんなか など）を伝える |
| U3-TEST-1 | 切り抜き・縮小・塗りつぶし・枠の並べ替え・枠の大きさの注意・伏せ字の規則は、純粋な関数にして単体テストを付ける（カバレッジ 90%） |
| U3-TEST-2 | E2E：偽物の AI で、写真を選ぶ → 囲む → 塗る → 送る → 1問ずつ確かめる → 登録。送られた画像の大きさが枠と同じで、塗ったところが黒いことを、通信の中身で確かめる |
