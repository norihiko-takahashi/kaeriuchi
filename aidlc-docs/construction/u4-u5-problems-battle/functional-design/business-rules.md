# U4・U5 機能設計：ビジネスルール

2026-11-09 にチャットで1つずつ決めたもの（★）と、それに合わせた細かいルール。

## BR-45-1 入り口 ★

- 「間違えた問題を手で入れる画面」は、**子どもが自分で使える**（ホームの「てで いれる」）。
- 入力：教科（必須・ボタンで選ぶ）、問題文（必須・200字まで）、きみの答え（必須・100字まで）、正しい答え（必須・100字まで）。
- 1日に登録できる間違いの数（BR-3.1、初期値10問）を数える。

## BR-45-2 検証に落ちたとき ★

| 状況 | 扱い |
|---|---|
| 問題が検証に落ちた | その問題は出さない |
| 足りなくなった | 1回だけ作り直す |
| 作り直しても足りない | 通った問題が2問以上なら、その数で戦う。1問以下なら「うまく つくれなかったよ。あとで もう一回 ためしてね」と出し、ミスモンは残す（あとで戦える） |
| 検証していない問題 | **絶対に出さない** |

## BR-45-3 問題の数 ★

| バトル | 問題の数 | 構成 |
|---|---|---|
| 初回 | 3問 | 同型問題・ポイント問題・確認問題 |
| 再来（U6） | 2問 | 同型問題・確認問題（前に出した問題とは変える） |

## BR-45-4 間違えたとき ★

| 回 | 間違えたら |
|---|---|
| 1回目 | ヒント1を見せて、もう一度 |
| 2回目 | ヒント2を見せて、もう一度 |
| 3回目 | 答えと解説を見せて、次の問題へ（その問題はダメージなし） |

- 「ヒント」ボタンで、間違える前にヒントを見ることもできる（見た分だけ、もらえる XP が少し減る。XP は U6）。

## BR-45-5 HP とダメージ

- ミスモンの HP は、問題の数 × 100。
- 正解のダメージは、1回目の正解 100、2回目 70、3回目 40（ヒントを見た分だけ減る）。
- 報告で外した問題は、100 のダメージ（子どもが損をしない）。1回のバトルで外せるのは1問まで。

## BR-45-6 結果

| 結果 | 条件 | そのあと |
|---|---|---|
| 撃破 | 全問を3回以内に正解（報告で外した問題を含む） | 再来の日程に入る（U6） |
| あと一歩 | 答えを見た問題が1問でもある | 翌日にまた出てくる。罰はない |
| 撤退 | 途中でやめた | 続きから再開できる |

## BR-45-7 ルールでの採点（端末）

| 答え方 | 正解とみなすもの |
|---|---|
| 数値 | 全角・半角を区別しない。前後の空白を無視。分数・小数・整数を数として比べる（`1/2` と `0.5` は同じ。約分していない分数も、値が同じなら正解）。単位が決まっていれば、単位は付けても付けなくてもよい |
| 選択式 | 選んだ選択肢が正解と同じ |
| 短い文 | 同じ意味の答えの一覧のどれかと一致（全角・半角、ひらがな・カタカナ、前後の空白を区別しない）。一覧で判断できず、似ているときだけ AI で採点する |
| 並べ替え | 順番が正解と同じ |
| 自己採点 | お手本を見て、子どもが「できた／もう一回」を選ぶ |

## BR-45-8 報告 ★

- 理由：「こたえが まちがってる」「もんだいが へん」「よみとりが まちがってる」「むずかしすぎる・かんたんすぎる」「そのほか（自由入力・100字まで）」
- 保存するもの：問題の中身（文字）、ミスモンの文字の情報、理由、プロンプトの版、AI のプロバイダーとモデル。**画像とニックネームは含めない**
- U8 ができるまで、端末に保存して送信待ちに入れる。保護者メニューで一覧を見られる
