# U4・U5 インフラ設計：問題の生成と検証、バトル

U4・U5 では、新しいクラウドの資源は作りません。

| 項目 | 内容 |
|---|---|
| AWS | U2 と同じ。検証役は `BEDROCK_MODEL_VERIFY`（初期値は作る側と同じモデル）。IAM の権限は変えない（Guardrails を使わないため） |
| 端末 | IndexedDB のスキーマを v2 にする（ミスモン、問題、バトル） |
| Service Worker | バトルの画面を、ほかの画面と同じく事前にキャッシュする。AI の API はキャッシュしない |
| CI | 追加の仕組みはなし。単体テスト・E2E・評価のコマンド（Mock）に、U4・U5 の分が増える |
| 本番 | U8 までは AI の API は本番で止めたまま（U2 の決まり） |
