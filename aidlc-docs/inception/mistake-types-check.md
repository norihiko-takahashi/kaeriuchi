# 間違いのタイプ 80個の照らし合わせ（2026-11-12）

`content/mistake-types/*.json` の下書き（AI が作成）を、Web 上の資料と照らし合わせた結果。

## 何を確かめたか

1. **学年**：その単元が、学習指導要領（平成29年告示。小学校は 2020年度、中学校は 2021年度から）で何年生に置かれているか
2. **つまずき**：よくある間違いとして、全国学力・学習状況調査の分析資料などに出てくるか
3. **例の正しさ**：例の「間違った答え」が、その間違い方で本当に出てくる答えか。「正しい答え」が合っているか（80個すべて計算・確認した）

### 限界

- 文部科学省のサイト（www.mext.go.jp）は、この作業の環境からは開けなかった（ネットワークの設定で止められている）。そのため、学習指導要領の本文は、それを引用している都道府県の教育委員会・教科書会社の資料と検索結果で確かめた。**本文そのものでの確認は、β版の前の元教員の見直しで行う。**
- 教科書会社ごとの単元の順番（何学期か）までは見ていない。

## 直したもの（7個）

| ID | 前 → 後 | 理由 |
|---|---|---|
| math.speed.relation（速さ） | 小6 → 小5・小6 | 平成29年の改訂で、速さは6年から5年へ移った（奈良県・埼玉県の説明資料）。6年でも復習で出るので残した |
| math.decimal.align（小数のたし算・ひき算） | 小4・5 → 小3〜5 | 小数第一位までのたし算・ひき算は3年。4年で 1/100 の位以下に広がる |
| math.fraction.add-denominators（分母どうしも足す） | 小5 → 小3〜5 | 分母が同じ分数のたし算は3・4年。1/5 + 2/5 = 3/10 のような間違いは、分母が同じときから出る |
| japanese.idiom.meaning（ことわざ・慣用句） | 小4〜中1 → 小3〜中1 | 学習指導要領では3・4年の内容。教科書では3年に「ことわざ・故事成語」、4年に「慣用句」 |
| japanese.grammar.subject-predicate（主語と述語） | 小2〜6 → 小1〜6 | 1・2年の内容「文の中における主語と述語との関係に気付くこと」 |
| science.circuit.series-parallel（直列・並列） | 小4・小6 → 小4・中2 | 小4「電流の働き」で乾電池のつなぎ方を学ぶ。小6「電気の利用」は発電・蓄電が中心で、つなぎ方は扱わない。中2で直列・並列回路の電流・電圧を学ぶ |
| social.climate.region（日本の気候） | 小5・中1 → 小5・中1・中2 | 中学の地理で日本の地域の特色を学ぶのは、1年の終わり〜2年が多い |

## そのままにしたもの（確かめて問題なし）

- **算数・数学**：繰り上がり・繰り下がり（1〜3年）、九九（2年）、あまりのあるわり算（3年）、商に 0 が立つわり算（4年）、計算の順序（4年）、帯分数（4年）、約分（5年）、分数のわり算（6年）、面積（4・5年）、分度器（4年）、割合（5年）、中学の正負の数・文字式・方程式（1年）、一次関数（2年）、因数分解・平方根（3年）
- **国語**：小さい「っ」・のばす音・「は・へ・を」（1・2年）、カタカナ（1・2年）、敬語（5・6年、中2）、歴史的仮名遣い（中学）
- **英語**：小学校は5・6年が教科。過去形は「よく使う基本的なもの」だけ小学校で扱い、文法として学ぶのは中学。三人称単数・疑問文・否定文・進行形（中1）、比較（中2）、受け身・現在完了（中2〜3）
- **理科**：植物のつくり（3〜6年）、水のすがた（4年）、月（4年「月と星」・6年「月と太陽」）、条件をそろえる実験（5年が中心）、密度（中1）、オームの法則（中2）
- **社会**：八方位・地図記号（3・4年）、都道府県（4年）、産業（5年）、歴史（6年・中学）、三権（6年・中3）

## つまずきの裏付け（全国学力・学習状況調査など）

- **割合**（math.ratio.base）：「もとにする量・くらべる量・割合の関係」は、全国学調で長く続いている課題として、鳥取県・栃木県・広島県の分析資料に出てくる。かけ算とわり算の取り違えが典型的な誤答
- **速さ・単位量あたり**（math.speed.relation）：2024年度の調査で苦手な子が多い単元として報じられている
- そのほかの多くは、教科書や指導案で「つまずきやすい」とされる定番のもの。全国学調の報告書（国立教育政策研究所）そのものとの照らし合わせは、文部科学省・国立教育政策研究所のサイトが開けるようになってから行う

## 気になったが、直さなかったもの

- **science.term.confusion の例「光合成」**：「光合成」という言葉は中学で学ぶ（小6は「葉に日光が当たるとでんぷんができる」まで）。この型の学年（小3〜中3）は「用語の取り違え」全体の学年なので、そのままにした。例は中学生向けとして読む
- **japanese.kanji.okurigana（送りがな）**：学習指導要領では3・4年の内容だが、漢字を習う1・2年から間違いが出るので、小2からのままにした
