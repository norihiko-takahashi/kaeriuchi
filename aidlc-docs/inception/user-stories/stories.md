# ユーザーストーリー

優先度：**M** = MVP に必須 / **S** = MVP にあるとよい / **L** = MVP より後
各ストーリーの「受け入れ基準」は Given / When / Then（前提 / 操作 / 結果）の形で書きます。

---

## Epic E1. はじめての設定

### US-1.1 保護者がアカウントを作る 【M】（P4）
保護者として、数分で設定を終えて、子どもに使わせ始めたい。
- 受け入れ基準
  - Given 初めてアプリを開いた / When 保護者が同意事項（画像の扱い、AI の利用、データの保存先）を読んで同意する / Then 子どものプロフィール作成に進める
  - 同意しない場合は、先に進めない
  - 同意事項は、小学生にもわかる版と、保護者向けの詳しい版の2つを用意する

### US-1.2 子どものプロフィールを作る 【M】（P4）
保護者として、子どものニックネームと学年だけを登録したい。
- 受け入れ基準
  - ニックネーム、学年（小1〜中3）、アバターの3つでプロフィールを作れる
  - 学年によって、表示モード（低学年・高学年・中学生）が自動で決まる。手動でも変えられる
  - ニックネームを入れる前に、「本名をニックネームにしない」理由をイラストつきで説明する画面が出る。保護者と子どもが一緒に読む前提で、「わかった」を押すと先に進める（説明の文章の案は `data-inventory.md` §3）
  - ニックネームは自由に入力できる。本名らしいときは、やさしく確認するだけで、入力は止めない

### US-1.3 プロフィールを選んで始める 【M】（P1, P2, P3）
子どもとして、自分のアイコンをタップするだけで始めたい。

### US-1.4 保護者がパスワードなしでログインする 【M】（P4）
保護者として、パスワードを覚えずにログインしたい。
- 受け入れ基準
  - メールアドレスを入れると、ログイン用のリンクが届き、それを開くとログインできる
  - ログインした後、パスキー（指紋・顔など）を登録すれば、次からはそれでログインできる

### US-1.5 別の端末でも同じデータを使う 【M】（P3, P4）
保護者として、子ども用のタブレットと自分のスマホで、同じデータを見たい。
- 受け入れ基準
  - Given タブレットで撃破したミスモンがある / When 保護者が自分のスマホでログインする / Then そのミスモンと成績が表示される
  - オフラインのときにバトルした結果は、オンラインに戻ったら同期される
  - 2つの端末で同時に使っても、XP やバトルの記録が消えない

## Epic E2. 間違いを撮る

### US-2.1 宿題を撮影する 【M】（P1, P2, P3）
子どもとして、間違えた問題をカメラで撮って、ミスモンを呼び出したい。
- 受け入れ基準
  - Given ホーム画面 / When 「ミスモンをよぶ」を押す / Then カメラが起動する
  - カメラの権限を拒否された場合は、写真を選んで取り込む方法を案内する

### US-2.2 間違えた部分だけを切り抜く 【M】（P1, P2, P3）
子どもとして、間違えた問題だけを四角で囲んで選びたい。
- 受け入れ基準
  - 指で四角の範囲を動かして調整できる
  - 送信されるのは、切り抜いた範囲の画像だけ（ネットワークの通信内容で確認する）
  - 囲んだ範囲が小さすぎる・大きすぎるときは、注意を出す

### US-2.3 1枚の写真から、間違いを複数登録する 【S】（P3）
中学生として、プリント1枚にある間違いをまとめて登録したい。

### US-2.4 写真を選んで取り込む 【M】（P3, P4）

## Epic E3. 解析と確認

### US-3.1 解析結果を確認する 【M】（P2, P3, P4）
子どもとして、AI が読み取った問題と答えが合っているかを確かめたい。
- 受け入れ基準
  - Given 解析が終わった / Then 「もんだい」「きみのこたえ」「せいかい」「まちがいのタイプ」が表示される
  - それぞれをタップすると直せる
  - 信頼度が低い項目は色を変えて表示し、確認しないと先に進めない

### US-3.2 解析に失敗したときに手で入力する 【M】（P2, P4）
- 受け入れ基準
  - 読み取れなかったときは「とりなおす」「じぶんでいれる」を選べる
  - 手で入力しても、かえりうち問題は作られる

### US-3.3 名前などが写っていたら注意される 【S】（P4）
保護者として、子どもの名前や学校名が写った画像は送られないようにしたい。
- 受け入れ基準は、課題 R1 の検証の結果で決める

## Epic E4. かえりうちバトル

### US-4.1 かえりうち問題を解く 【M】（P1, P2, P3）
子どもとして、自分の間違いに合った問題を解いて、ミスモンをやっつけたい。
- 受け入れ基準
  - 同型問題、ポイント問題、確認問題を、合わせて3〜5問出す
  - 正解するとミスモンにダメージの演出が出て、HP が減る
  - すべての問題で正答の検証が済んでいる（検証に失敗した問題は出さない）

### US-4.2 ヒントを見る 【M】（P1, P2）
- 受け入れ基準
  - ヒントは2段階。1回目に間違えたとき、または「ヒント」ボタンを押したときに出す
  - ヒントを使っても撃破はできる（もらえる XP は少し減る）

### US-4.3 解説を見る 【M】（P2, P3）
- 受け入れ基準
  - 解いたあと、なぜ最初の答えが間違っていたかを、自分の答えと並べて説明する

### US-4.4 問題の答え方が教科に合っている 【M】（全員）
- 受け入れ基準
  - 算数・数学：数字のキーパッド、分数・小数の入力
  - 英語：単語の並べ替え、スペルの入力
  - 国語：選択式、読みの入力、漢字のお手本を見ての自己採点
  - 理科・社会：選択式、用語の入力（表記の揺れを許す）

### US-4.5 途中でやめて、あとで続きから解く 【M】（P1）

### US-4.6 おかしい問題を報告する 【S】（P3, P4）

## Epic E7. 保護者

### US-7.1 間違いの傾向を見る 【S】（P4）
- 受け入れ基準
  - 保護者が自分のスマホでログインして見られる
  - 教科別、間違いのタイプ別の件数と、撃破率の推移を見られる
  - 「よくある間違い TOP5」と、AI がまとめた傾向の説明が表示される

### US-7.2 使い方のルールを設定する 【M】（P4）
- 受け入れ基準
  - 1日の撮影回数の上限、使える時間帯を設定できる
  - 保護者向けの画面に入るには、PIN または端末の認証（指紋・顔など）が必要

### US-7.3 データを書き出す・削除する 【M】（P4）
- 受け入れ基準
  - 子どもごと、またはアカウントごとに削除できる。削除すると、クラウドのデータも削除される

## MVP の範囲のまとめ

MVP には、**M** のストーリーをすべて含めます。代表的な流れは次のとおりです。

1. 保護者がメールのリンクでログインして同意し、子どものプロフィールを作る（E1）
2. 子どもが撮影して切り抜き、解析結果を確認する（E2, E3）
3. かえりうちバトルを解いてミスモンを撃破し、XP と図鑑の登録をもらう（E4, E5）
4. 翌日以降にミスモンが再来し、もう一度倒す（E6）
5. 保護者が自分のスマホでログインし、使い方のルールを設定し、データを書き出す・削除する（E1, E7）
