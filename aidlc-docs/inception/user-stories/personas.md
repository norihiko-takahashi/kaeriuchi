# ペルソナ

## P1. ゆうと（小学2年生・低学年）
- 宿題で多いのは、算数の繰り上がりのある足し算と、漢字の書き取り。
- 文字を読むのはまだゆっくりで、長い文章を読むと疲れてしまう。
- 間違いを指摘されるとすねてしまうが、シールやキャラクターを集めるのが大好き。
- **必要なもの**：ふりがな、読み上げ、大きなボタン、1画面に1つの操作、すぐにほめてもらえること。

## P2. さくら（小学5年生・高学年）
- 苦手は分数の計算と、社会の用語（地名や産業）。
- 自分でタブレットを使える。図鑑をコンプリートしたいタイプ。
- **必要なもの**：自分だけで撮影から解き終わるまでできること、図鑑や連続記録などの「集める」楽しさ、ボス戦。

## P3. はると（中学2年生）
- 苦手は数学の連立方程式と、英語の文法（三単現、過去形）。
- 定期テスト前に、提出物の間違いをまとめて直したい。
- 子どもっぽい見た目は嫌がる。
- **必要なもの**：まとめて撮影できること、早く解ける操作、見た目を落ち着いたものに変えられる「中学生モード」、テスト前にまとめて復習できること。

## P4. 保護者（40代・共働き）
- 毎晩、宿題の丸付けはするが、なぜ間違えたのかまで付き合う時間はない。
- 子どもがスマホを使いすぎること、個人情報が漏れることを心配している。
- **必要なもの**：数分で設定が終わること、使う時間の制限、どんな間違いをしやすいかがわかるまとめ、データの安全性がわかる説明。
