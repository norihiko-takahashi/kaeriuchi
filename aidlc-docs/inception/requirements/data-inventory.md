# 扱うデータの一覧（プライバシー）

2026-11-08 の議論で決めた内容です。新しいデータを集めたいときは、まずこの表に追加して、レビューを受けてください。

## 1. 集めないもの

| 項目 | 理由 |
|---|---|
| 本名 | 入力欄を作らない。写り込んだものも送らない・残さない（写り込みの対策は課題 R1） |
| 学校名・クラス・先生の名前 | 同上 |
| 生年月日・年齢 | 学年だけで、表示も問題の難しさも切り替えられる |
| 性別 | 問題の作成にもゲームにも使わない |
| 都道府県・地域 | 学年と組み合わせると、誰なのかを絞り込みやすくなる |
| 教科書の出版社 | MVP では集めない。地域と組み合わせると学校を推測できる |
| 子どもの写真（アバター） | アバターはプリセットから選ぶだけ。写真はアップロードさせない |
| 使った時刻 | 保存するのは日付だけ。時刻からは、生活のリズム（何時に家に一人でいるか、など）がわかってしまう |

## 2. 集めるもの

| 項目 | 必要な理由 | 保存先 | 保存する期間 |
|---|---|---|---|
| 保護者のメールアドレス | ログイン（マジックリンク） | クラウド | 退会するまで。宣伝のメールは、同意したときだけ送る |
| ニックネーム | 画面に表示するため | クラウド | 退会するまで |
| 学年 | 問題の難しさ、表示モード | クラウド | 退会するまで |
| アバターの設定 | 画面に表示するため | クラウド | 退会するまで |
| ミスモン（問題文・答え・間違いのタイプ） | 学習の中心 | クラウド | 退会するまで、または保護者が削除するまで |
| バトルの記録・ゲームの状態 | 学習の中心 | クラウド | 同上 |
| サムネイル画像（切り抜いたもの） | 図鑑とミスモンの表示 | **端末内だけ** | 端末のデータを消すまで |
| 解析に使った画像 | AI の解析 | **サーバーのメモリ上だけ** | 解析が終わるまで |
| IP アドレス・端末の情報 | 不正利用の対策、障害の調査 | サーバーのログ | 14日。学習データとは結びつけない |
| 確認画面で直された内容（文字だけ） | 解析の精度を測る（評価用データの B4） | クラウド | 退会するまで。画像は含めない |
| プッシュ通知の宛先（トークン） | 再来のお知らせ | クラウド | 通知をオンにしている間だけ |

## 3. ニックネーム

- 自由に入力できる。
- **プロフィールを作るときに、保護者と子どもが一緒に「本名をニックネームにしない」理由を確認する画面**を入れる（US-1.2）。
  - 小中学生向けに、イラストつきで、本名を入れたときのリスクをわかりやすく説明する。
  - 保護者向けには、短い補足を添える。
- 入力されたニックネームが本名らしい場合（漢字の姓名の形、など）は、**やさしく確認するだけ**で、入力は止めない（判定の方法は課題 R1 と一緒に検証する）。

### 説明画面の文章（案）

イラストは仮の SVG で作り、後から差し替えます（OQ6）。表示の仕方は、低学年・高学年・中学生のモードに合わせて変えます。

1. **「なまえは きみの たいせつな ひみつ」**
   ほんとうの なまえは、きみが だれなのかが わかる だいじな じょうほうだよ。
   （イラスト：ミスモンが、名札のついた宝箱を守っている）
2. **「しらない ひとに しられると…」**
   なまえと がくねんが わかると、しらない ひとが きみを さがせて しまうことが あるんだ。
   （イラスト：画面の向こうから、知らない影がのぞいている。こわくなりすぎない絵柄にする）
3. **「かえりうちネームを つけよう！」**
   すきな もの・どうぶつ・ひっさつわざ なんでも OK！ おうちの ひとと いっしょに かんがえてね。
   （例：「ほのおのきつね」「さんすうマスター」）
   （イラスト：子どもと保護者が、一緒に名前を考えている）

保護者向けの補足：「ニックネームは画面の表示に使い、クラウドにも保存します。本名や、学校で使っているあだ名は避けてください。」

## 4. 外部への受け渡し

| 渡す先 | 渡すもの | 渡さないもの | 確認すること |
|---|---|---|---|
| AI プロバイダー（Bedrock） | 切り抜いた画像、学年、教科 | ニックネーム、ID、保護者の情報 | 入力を保存しないか、学習に使わないか、不正利用の監視のためにデータを残すか。リージョンをまたぐ推論を使うかどうか（国内で処理するかどうか） |
| エラーの記録（Sentry など） | エラーの種類、スタックトレース | 画像、問題文などの文字の項目（送る前に消す） | |
| 外部の分析ツール・広告 | **何も渡さない**（子ども向けの画面には SDK を入れない） | | |
| 問い合わせの窓口 | 問い合わせの文章 | | 学習データとは別に管理する |

## 5. 運用者がデータを見ること

- 運用者が学習データを見るのは、保護者からの問い合わせに対応するときだけにする。
- 見たときは、誰がいつ何を見たかのログを残す。
