# かえりうち

> 宿題の間違いを撮影すると、その間違い専用の問題が出るゲーミフィケーション学習アプリ（小中学生・全教科 / PWA）

間違えた問題は「ミスモン（間違いモンスター）」として現れます。専用の問題に正解してミスモンを**返り討ち**にし、
時間をおいて再び現れるミスモンも倒して、苦手を「わかった」に変えていきます。
